# Django: Creating a New App (`startapp`)

An "App" in Django is a web application that does something—for example, a blog system, a database of public records, or a small polling app. A "Project" is a collection of configuration and apps for a particular website.

## 1. The Command
To create a new app, run this in your terminal at the root level (where `manage.py` is):

```bash
python manage.py startapp app_name
